АРХИТЕКТУР
  - Замын бүтцийг feature-based болгон бүрэн шинэчиллээ
    lib/
    ├── core/           ← API client, error, utils, theme, services
    ├── features/
    │   ├── models/     ← Domain моделууд
    │   └── presentation/
    │       ├── controllers/
    │       ├── data/repository/
    │       └── pages/
    └── shared/         ← Widgets, mixins

  - sealed class Result<T> { Ok<T> | Err } — repository return type
  - sealed class AsyncValue<T> — AsyncLoading / AsyncData / AsyncError
  - Dart 3 pattern matching ашиглан switch шийдэл
  - ApiService (Dio singleton) — token interceptor, 401 auto-logout
  - Authenticator (Hive) — User persist, onUnauthorized callback

AUTHENTICATION
────────────────────────────────────────────────────────────────────────────────

  Multi-step login (email → password | activate | notRegistered)
    endpoint: POST auth/check-email
    endpoint: POST auth/login
    endpoint: POST auth/activate
    endpoint: POST auth/activate/request-otp

  AuthController
    - LoginStep enum: email, password, activate, notRegistered
    - checkEmail()     → email шалгаж алхам тодорхойлно
    - login()          → нууц үгээр нэвтэрнэ
    - activate()       → OTP + шинэ нууц үгээр идэвхжүүлнэ
    - requestOtp()     → OTP дахин илгээнэ
    - resetToEmail()   → email алхам руу буцна
    - maskedPhone      → "9999****99" masked утасны дугаар

  LoginScreen
    - AnimatedSwitcher + FadeTransition + SlideTransition (ValueKey(step))
    - _EmailStep / _PasswordStep / _ActivateStep / _NotRegisteredStep
    - OTP талбар: 6 оронтой, letterSpacing:6, centered

VALIDATORS  (lib/core/utils/validators.dart)
────────────────────────────────────────────────────────────────────────────────

  Web-тэй яг нийцэх дүрмүүд (carservice.mn):
    email    → /^[^\s@]+@[^\s@]+\.[^\s@]+$/
    phone    → 8 оронтой MN (5-9 эхэлсэн), 976/+976/0-prefix арилгана
    password → min 8 тэмдэгт
    plate    → /^\d{4}[А-ЯЁӨҮA-Z]{3}$/  (жш: 1234ҮНА)
    otp      → яг 6 оронтой тоо

  AppValidators (static):
    required(v, label), email(v), phone(v), password(v),
    confirmPassword(v, original), plate(v), otp(v),
    minLength(min, label), combine([...])
    isValidEmail(), isValidPhone(), isValidPlate()

  ValidatorMixin (State-д `with ValidatorMixin`):
    emailValidator, phoneValidator, plateValidator,
    passwordValidator, otpValidator
    requiredField(label), confirmPassword(original),
    minLength(min, label), combine([...])

  Ашигласан газрууд:
    new_customer_sheet.dart, new_vehicle_screen.dart,
    unit_list_screen.dart, labor_category_list_screen.dart,
    create_service_screen.dart, login_screen.dart
